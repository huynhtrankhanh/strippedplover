# Stripped Plover Protocol Documentation

Stripped Plover uses a simple JSON line protocol for communication over STDIO. Each message is a single line of JSON, and all messages follow a request-response pattern.

## Protocol Format

### Request Format

```json
{
  "id": "<unique-client-generated-id>",
  "method": "<method-name>",
  "params": { ... }
}
```

- `id`: A unique identifier generated by the client. The server will include this ID in the response.
- `method`: The method to invoke.
- `params`: Method-specific parameters (optional for some methods).

### Response Format

**Success Response:**
```json
{
  "id": "<request-id>",
  "result": { ... }
}
```

**Error Response:**
```json
{
  "id": "<request-id>",
  "error": {
    "code": <error-code>,
    "message": "<error-message>"
  }
}
```

### Error Codes

| Code | Description |
|------|-------------|
| -32700 | Parse error (invalid JSON) |
| -32601 | Unknown method |
| -32000 | General error |

## Startup

When Stripped Plover starts, it outputs a ready message:

```json
{"status": "ready"}
```

## Output Model: Preedit and Commit

Stripped Plover uses a preedit/commit model suitable for IME integration:

- **Preedit**: Uncommitted text that can be completely replaced by subsequent strokes. The IME should display this as "composing" text.
- **Commit**: Finalized text that the user has explicitly confirmed.

This model eliminates the need for backspaces - instead, the entire preedit buffer is replaced with each stroke.

## Methods

### Translation

#### `translate`

Translate a stenotype stroke. The translation engine is stateful - it considers previous strokes to form multi-stroke translations.

**Request:**
```json
{
  "id": "1",
  "method": "translate",
  "params": {
    "stroke": "TEFT"
  }
}
```

**Response:**
```json
{
  "id": "1",
  "result": {
    "preedit": "test",
    "key_combinations": []
  }
}
```

The response includes:
- `preedit`: The complete current preedit text. Replace any existing preedit with this value.
- `key_combinations`: Array of literal key combinations to execute (e.g., `["Control_L(c)"]`)

**Example multi-stroke session:**
```
Input: TEFT
Response: {"preedit": "test", "key_combinations": []}

Input: -G
Response: {"preedit": "testing", "key_combinations": []}  // Entire preedit updated

Input: *  (undo stroke)
Response: {"preedit": "test", "key_combinations": []}  // Reverts to previous state
```

#### `commit`

Commit the current preedit text. This finalizes the preedit and clears it.

**Request:**
```json
{
  "id": "2",
  "method": "commit",
  "params": {}
}
```

**Response:**
```json
{
  "id": "2",
  "result": {
    "committed": "test"
  }
}
```

After commit, the preedit is cleared but the translation state is preserved for multi-stroke translations.

#### `reset_state`

Reset the translation state completely. This clears both the translator state and the preedit buffer.

**Request:**
```json
{
  "id": "3",
  "method": "reset_state",
  "params": {}
}
```

**Response:**
```json
{
  "id": "3",
  "result": {
    "status": "ok"
  }
}
```

Use this when focus changes or when starting a new input context.

### Dictionary Management

#### `add_dictionary`

Add a dictionary file to the engine.

**Request:**
```json
{
  "id": "3",
  "method": "add_dictionary",
  "params": {
    "path": "/path/to/dictionary.json"
  }
}
```

**Response:**
```json
{
  "id": "3",
  "result": {
    "status": "ok",
    "path": "/path/to/dictionary.json",
    "entries": 12345
  }
}
```

#### `remove_dictionary`

Remove a dictionary from the engine.

**Request:**
```json
{
  "id": "4",
  "method": "remove_dictionary",
  "params": {
    "path": "/path/to/dictionary.json"
  }
}
```

**Response:**
```json
{
  "id": "4",
  "result": {
    "status": "ok",
    "path": "/path/to/dictionary.json"
  }
}
```

#### `list_dictionaries`

List all loaded dictionaries.

**Request:**
```json
{
  "id": "5",
  "method": "list_dictionaries",
  "params": {}
}
```

**Response:**
```json
{
  "id": "5",
  "result": {
    "dictionaries": [
      {
        "path": "/path/to/dictionary.json",
        "enabled": true,
        "readonly": false,
        "entries": 12345
      }
    ]
  }
}
```

#### `get_dictionary_entries`

Get all entries from a specific dictionary.

**Request:**
```json
{
  "id": "6",
  "method": "get_dictionary_entries",
  "params": {
    "path": "/path/to/dictionary.json"
  }
}
```

**Response:**
```json
{
  "id": "6",
  "result": {
    "path": "/path/to/dictionary.json",
    "entries": [
      {"stroke": "TEFT", "translation": "test"},
      {"stroke": "HEL/HROE", "translation": "hello"}
    ]
  }
}
```

### Entry CRUD Operations

#### `add_entry`

Add an entry to a dictionary.

**Request:**
```json
{
  "id": "7",
  "method": "add_entry",
  "params": {
    "stroke": "TEFT",
    "translation": "test",
    "path": "/path/to/dictionary.json"
  }
}
```

The `path` parameter is optional. If not specified, the entry is added to the first writable dictionary.

**Response:**
```json
{
  "id": "7",
  "result": {
    "status": "ok",
    "stroke": "TEFT",
    "translation": "test"
  }
}
```

#### `remove_entry`

Remove an entry from a dictionary.

**Request:**
```json
{
  "id": "8",
  "method": "remove_entry",
  "params": {
    "stroke": "TEFT",
    "path": "/path/to/dictionary.json"
  }
}
```

The `path` parameter is optional. If not specified, the entry is removed from the first dictionary that contains it.

**Response:**
```json
{
  "id": "8",
  "result": {
    "status": "ok",
    "stroke": "TEFT"
  }
}
```

#### `update_entry`

Update an existing entry in a dictionary.

**Request:**
```json
{
  "id": "9",
  "method": "update_entry",
  "params": {
    "stroke": "TEFT",
    "translation": "testing",
    "path": "/path/to/dictionary.json"
  }
}
```

The `path` parameter is optional. If not specified, the entry is updated in the first dictionary that contains it.

**Response:**
```json
{
  "id": "9",
  "result": {
    "status": "ok",
    "stroke": "TEFT",
    "translation": "testing"
  }
}
```

### Lookup Operations

#### `lookup`

Look up a stroke in the dictionaries.

**Request:**
```json
{
  "id": "10",
  "method": "lookup",
  "params": {
    "stroke": "TEFT"
  }
}
```

**Response:**
```json
{
  "id": "10",
  "result": {
    "stroke": "TEFT",
    "translation": "test"
  }
}
```

If the stroke is not found, `translation` will be `null`.

#### `reverse_lookup`

Look up all strokes that produce a given translation.

**Request:**
```json
{
  "id": "11",
  "method": "reverse_lookup",
  "params": {
    "translation": "test"
  }
}
```

**Response:**
```json
{
  "id": "11",
  "result": {
    "translation": "test",
    "strokes": ["TEFT", "TE*S"]
  }
}
```

### Control

#### `quit`

Stop the engine.

**Request:**
```json
{
  "id": "12",
  "method": "quit",
  "params": {}
}
```

**Response:**
```json
{
  "id": "12",
  "result": {
    "status": "ok"
  }
}
```

## IME Integration Notes

When integrating with an IME:

1. **Preedit Text**: The `preedit` field contains the complete current uncommitted text. On each `translate` response, replace the entire preedit buffer with this value.

2. **No Backspaces**: This protocol does not use backspaces. The preedit is always provided as a complete string that replaces any previous preedit.

3. **Commit**: Call the `commit` method when the user wants to finalize input (e.g., pressing space, Enter, or losing focus). This returns the committed text and clears the preedit.

4. **Key Combinations**: Some translations include literal key presses (like `{#Control_L(c)}` for Ctrl+C). These are returned in the `key_combinations` array and should be executed by the IME.

5. **State Management**: Call `reset_state` when focus changes or when starting a new input context. This clears both the preedit and the translation state.

6. **Undo**: The `*` stroke (asterisk) is the undo stroke in stenography. When processed, it will update the preedit to reflect the undone state.

## Steno Stroke Format

Strokes use the RTFCRE format (steno notation). Examples:
- `TEFT` - a single stroke
- `HEL/HROE` - a multi-stroke outline (strokes separated by `/`)
- `*` - asterisk (correction/undo key)
- `-G` - right-hand key with explicit hyphen
